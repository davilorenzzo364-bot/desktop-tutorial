# Welcome to GitHub Desktop!

**Uma IDE leve, personalizável e com suporte a múltiplas linguagens de programação.**

## 📌 Sobre o projeto

A Forja IDE é um ambiente de desenvolvimento integrado (IDE) criado com o objetivo de oferecer uma alternativa simples, leve e funcional para programadores.

Inspirada em IDEs como o Visual Studio Code, a Forja reúne editor de código, terminal integrado, explorador de arquivos, realce de sintaxe, sistema de mods e ferramentas para desenvolvimento em diversas linguagens.

O projeto foi desenvolvido em **Python**, utilizando a biblioteca gráfica **Tkinter**, priorizando simplicidade, organização e baixo consumo de recursos.

## 🛠️ Tecnologias utilizadas

- Python 3
- Tkinter (interface gráfica)
- JSON (armazenamento de configurações)
- PyInstaller (opcional, para empacotamento em executável)
- Ferramentas externas para compilação e execução das linguagens.

## 💻 Requisitos

Para executar a Forja IDE diretamente pelo código-fonte, é necessário:

1. Windows 10 ou compatível.
2. Python 3 instalado.
3. Tkinter disponível na instalação do Python.
4. Os arquivos do projeto extraídos em uma pasta.

**Importante:** A Forja IDE não é distribuída atualmente como um arquivo `.exe` independente. Ela é executada através do Python, utilizando o arquivo `Iniciar_Forja.bat`.

## 🔧 Compiladores e interpretadores

Os compiladores e interpretadores das linguagens são instalados separadamente. A Forja não inclui todas essas ferramentas em seu pacote.

Dependendo da linguagem utilizada, será necessário instalar ferramentas como:

- GCC / MinGW — C e C++
- JDK — Java
- .NET SDK — C#
- Node.js e TypeScript — JavaScript e TypeScript
- Python — Python
- Go — Go
- Rust — Rust
- Ruby — Ruby
- PHP — PHP
- FreeBASIC — BASIC
- Kotlin Compiler — Kotlin
- Luau CLI — Luau
- Arduino CLI — Arduino

O SQL utiliza o mecanismo SQLite disponível na integração da IDE.
