🔨 Forja IDE

A lightweight, customizable IDE with support for multiple programming languages.

📌 About the Project

Forja IDE is an Integrated Development Environment (IDE) designed to provide a simple, lightweight, and functional development environment for programmers.

Inspired by IDEs such as Visual Studio Code, Forja brings together a code editor, integrated terminal, file explorer, syntax highlighting, a mod system, and development tools for multiple programming languages.

The project is built with Python and the Tkinter GUI toolkit, prioritizing simplicity, organization, and low resource consumption.

🛠️ Technologies Used

- Python 3
- Tkinter (graphical user interface)
- JSON (configuration storage)
- PyInstaller (optional, for packaging the application as an executable)
- External tools for compiling and running programs in supported languages

💻 Requirements

To run Forja IDE directly from its source code, you need:

1. Windows 10 or a compatible Windows version.
2. Python 3 installed.
3. Tkinter available in your Python installation.
4. The project files extracted into a folder.

Important: Forja IDE is not currently distributed as a standalone ".exe" application. It runs through Python using the "Iniciar_Forja.bat" launcher.

🔧 Compilers and Interpreters

Compilers and interpreters must be installed separately. Forja does not include all language toolchains in its package.

Depending on the language you want to use, you may need tools such as:

- GCC / MinGW — C and C++
- JDK — Java
- .NET SDK — C#
- Node.js and TypeScript — JavaScript and TypeScript
- Python — Python
- Go — Go
- Rust — Rust
- Ruby — Ruby
- PHP — PHP
- FreeBASIC — BASIC
- Kotlin Compiler — Kotlin
- Luau CLI — Luau
- Arduino CLI — Arduino development

SQL uses the SQLite engine provided by the IDE's integration.

🚀 How to Run

1. Download or clone this repository.
2. Extract the files if you downloaded a ZIP archive.
3. Install Python 3.
4. Run "Iniciar_Forja.bat".
5. Forja IDE should launch.

✨ Main Features

- Code editor with syntax highlighting.
- Integrated terminal.
- File and folder explorer.
- Welcome screen.
- Session memory and restoration.
- Automatic saving.
- Mod system.
- Python debugging.
- Arduino integration using the F7 key.
- Support for multiple programming languages.

📦 Development Status

Forja IDE is an evolving project. New features, improvements, and bug fixes are developed progressively.

Contributions, suggestions, and bug reports are welcome.
